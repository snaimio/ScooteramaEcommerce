## 📌 Technical Overview
This project demonstrates foundational e-commerce logic in vanilla JavaScript. It encapsulates cart data state inside dedicated classes, preventing race conditions and ensuring accurate currency rounding.

### 💼 Technical Highlights
- **Object-Oriented Cart Model**: `Cart.js` managing item additions, quantity modifications, item removals, and state persistence.
- **Item Value Modeling**: `Item.js` encapsulating unit pricing, inventory SKUs, and calculated line-item totals.
- **Tax & Promotion Engine**: Dynamically calculates applicable sales tax (HST) and evaluates promotional coupon codes.
